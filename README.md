# SoftwareQA-Week7

This repo contains the `sections` and `evidence` directories as required by the Python Unit Testing assignment.

Each test should be run via the CLI by entering the respective section directory and executing the test script.

For example, to run the section 2 test:
- `cd ./unit-testing-assignment/sections/section2`
- `python3 ./tests.py`

To run via `unittest` module:
- `cd ./unit-testing-assignment/sections/section5`
- `python3 -m unittest -v`
