# SoftwareQA-Week7

This repo contains the `sections` and `evidence` directories as required by the Python Unit Testing assignment.

To run tests for sections 1-4, execute the following procedure:
- `cd ./unit-testing-assignment/sections/<desired section>`
- `python3 <test file name>`

To run tests in sections 5 and 6:
- `cd ./unit-testing-assignment/sections/<desired section>`
- `python3 -m unittest -v`

    OR

- `cd ./unit-testing-assignment`
- `python3 -m unittest -v sections.<desired section>.<desired test file>`
